# Medical Insurance Cost Prediction

This is a **Streamlit web app** that predicts the **annual medical insurance cost** of an individual based on their personal details like age, BMI, smoking status, number of children, and region.

💻 **Try it live here:**  
[Medical Insurance Cost Prediction App](https://medical-insurance-cost-prediction-cjf4uptd44r6c93bjahsen.streamlit.app/)

For more details and the full project, check out the **Colab notebook** in this repository.
